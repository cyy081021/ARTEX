# 成员任务详情与引导入口修复记录

日期：2026-11-11。功能提交：`2193833`。本机构建版本：`0.5.0-members-2193833`。本次更新 main，不创建 tag。

## 更新内容

- 团队的共享任务名称可进入独立成员详情，集中查看目标、状态、当前权限、消息和协作入口。成员监听器仅放行精确页面路径；详情 API 仍按团队、任务和成员授权。
- 会话分别显示 Worker 编号、执行设备和运行状态。初次打开优先选择可发送 Worker；筛选和自动刷新保留正在查看的会话，工作结束后继续保留其消息。
- 将统一的“不可发送引导”提示拆分为权限不足、暂停、排队、未开始、已结束、收尾和通道未就绪等原因。主 Agent 状态取其实际会话，而非整个任务的运行状态。
- 主 Agent 和 Planner 的共享视图仍只读，页面明确说明入口与原因。主 Agent 对话从主端原任务详情进入；正在执行且通道就绪的 Worker 接受跨设备引导。
- 访问被撤销或任务不再可见时，清除旧详情和输入区域；请求失败期间禁用发送。原有消息去重、增量补取和执行权限检查继续生效。
- 接入文档的 Windows 桥接命令补齐进程级 `-ExecutionPolicy Bypass`，不修改系统持久策略。

操作见[团队共享消息说明](team-shared-messages.md)。

- 上一轮部署备份已清理，保留本轮程序回滚检查点。检查点仅用于恢复原程序及随附资源，不包含本轮数据库快照，也不覆盖任务、证据、身份或配置。
