# 本地源码审阅查看器

1. 用现代浏览器直接打开本目录的 `index.html`。无需安装软件或启动 ARTEX。
2. 点击“选择 JSON 文件”，选择已经脱敏并单独保管的 `.json` 档案。页面将按原顺序显示标题和复核历史。
3. 点击“清空”移除当前展示，或再次选文件替换。换文件立即清除旧内容；读入失败时只显示提示，原文件保持原样。

## 文件格式

标题和原因须在导入前脱敏。查看器只校验字段与类型，不能识别自由文本中的姓名、密钥或其他敏感信息。页面不使用网络、日志、浏览器存储或文件写入接口。

| 位置 | 接受的格式 |
| --- | --- |
| 根对象 | 只接受必填的 `title` 和 `history`。 |
| `title` | 非空字符串，不能全为空白。 |
| `history` | 按显示顺序排列的数组，允许空数组，最多 500 条。 |
| 每条记录 | 必须是对象，只接受可选的 `reason` 字符串。字段缺失、为 `null` 或全为空白时，原位置显示“未提供原因”。 |

文件必须是 UTF-8 JSON，最多 256 KiB（262144 字节）。无效 JSON、未知字段或记录类型错误时拒绝整份档案。

## 离线验收

有 Node.js 22 时，可在本目录运行 `node --test viewer.test.cjs`，用内存中的人工数据复核格式、大小和晚到读取。浏览器验收可在断网状态下进行：打开已有的脱敏副本，检查标题与记录顺序，清空后重新选择；再选空文件或格式错误的文件，确认先前的记录不可见。
