# 本地源码审阅查看器

1. 用现代浏览器直接打开本目录的 `index.html`。无需安装软件或启动 ARTEX。
2. 用“选择 JSON 文件”打开已经脱敏的档案，或在“手动粘贴脱敏 JSON”文本框中输入内容，再按“显示档案”。可用 Tab 移到按钮，再按 Enter。查看器不会访问系统剪贴板。
3. 开始编辑文本或改选文件时，上一份结果立即消失。“显示档案”会清空输入框，成功时显示标题和复核历史，失败时只显示提示。“清空”或离开页面都会清除输入与结果。

## 文件格式

标题和原因须在导入前脱敏。查看器只校验字段与类型，不能识别自由文本中的姓名、密钥或其他敏感信息。页面不使用网络、日志、浏览器存储或文件写入接口。

| 位置 | 接受的格式 |
| --- | --- |
| 根对象 | 只接受必填的 `title` 和 `history`。 |
| `title` | 非空字符串，不能全为空白。 |
| `history` | 按显示顺序排列的数组，允许空数组，最多 500 条。 |
| 每条记录 | 必须是对象，只接受可选的 `reason` 字符串。字段缺失、为 `null` 或全为空白时，原位置显示“未提供原因”。 |

两种入口使用同一格式。文件必须是 UTF-8 JSON；粘贴文本按 UTF-8 编码计数。每份档案最多 256 KiB（262144 字节）。无效 JSON、未知字段或记录类型错误时拒绝整份档案。

## 离线验收

有 Node.js 22 时，可在本目录运行 `node --test viewer.test.cjs`，使用人工数据复核两种入口的格式、大小、清空和晚到读取。手动验收时，可先显示一份脱敏档案，再在文本框中输入无效 JSON。原档案应立即消失，点击“显示档案”后应只看到错误提示。
